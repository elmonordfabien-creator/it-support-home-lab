# Day 4 – Networking Fundamentals

## Objective

The objective of this lab was to identify Windows network configuration, test connectivity, perform DNS lookups, trace network routes, and document a basic network troubleshooting process.

## Concepts Learned

- IP address
- Subnet mask
- Default gateway
- DHCP
- DNS
- MAC address
- Network packet
- Network hop

## Commands Practiced

- `ipconfig`
- `ipconfig /all`
- `ping 127.0.0.1`
- `ping [default gateway]`
- `ping 8.8.8.8`
- `ping example.com`
- `nslookup example.com`
- `tracert example.com`

## Troubleshooting Method

1. Verify the IP configuration.
2. Test the local TCP/IP stack.
3. Test the default gateway.
4. Test external IP connectivity.
5. Test DNS resolution.
6. Verify that websites open.
