# Day 2 – Windows Fundamentals

## Objective

The objective of this lab is to learn how to use Windows Task Manager, manage local user accounts, understand account privileges, identify basic network configuration information, and document a troubleshooting process.

## Activities Completed

- Explored Task Manager
- Reviewed CPU and memory usage
- Verified virtualization status
- Created a local standard user
- Compared administrator and standard user accounts
- Used ipconfig to view network information
- Completed a slow-computer troubleshooting scenario

## Skills Practiced

- Windows system monitoring
- Local user management
- Account permissions
- Basic command-line usage
- Network configuration identification
- Technical troubleshooting
- Technical documentation
