# Day 5 – Ubuntu Virtual Machine

## Objective

The objective of this lab was to create and configure an Ubuntu Linux virtual machine using Oracle VirtualBox.

## Lab Environment

- Host operating system: Windows
- Virtualization platform: Oracle VirtualBox
- Guest operating system: Ubuntu 26.04 LTS
- Memory: 8 GB
- Processors: 4
- Virtual disk: 60 GB dynamically allocated
- Network mode: NAT

## Activities Completed

- Downloaded the Ubuntu ISO
- Created an Ubuntu virtual machine
- Configured virtual hardware
- Installed Ubuntu Desktop
- Created a Linux user account
- Tested network connectivity
- Updated package information
- Created a clean installation snapshot

## Commands Practiced

- `whoami`
- `pwd`
- `ls`
- `cat /etc/os-release`
- `ip addr`
- `ping -c 4 example.com`
- `sudo apt update`

## Concepts Learned

- Host operating system
- Guest operating system
- Hypervisor
- ISO installation image
- Virtual disk
- NAT networking
- Virtual machine snapshot
